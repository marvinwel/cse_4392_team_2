5. Numeric / quantity expressions
- a number of subject sections
- two types of loan items
- up to a maximum of 8 items
- a maximum of 8 items

The description explicitly states that a customer may borrow “up to a maximum of 8 items” and that the number of items on loan must be “less than 8.” 
6. Possession expressions
- a language tape has a title language
- a language tape has a level
- a book has a title
- a book has author(s)
AUM specifically identifies possession expressions such as has/have as one of the brainstorming categories.  The Library description contains these possession relationships directly. 
7. “Consist of / part of” expressions
- library is made up of a number of subject sections
- subject sections are part of the library
The first is the exact expression appearing in the source. The second is the corresponding part-of relationship expressed using AUM terminology; AUM defines aggregation as the relationship where one object is part of another. 
8. Containment / containing expressions
- library contains subject sections
- library contains a number of subject sections
These represent the containment relationship implied by the source's statement that the library is “made up of” subject sections. 
9. “X is a Y” expressions — generalization / specialization
- customer is a member
- language tape is a loan item
- book is a loan item
The first is stated directly as “Each customer is known as a member.” The latter two are supported by the statement that there are two types of loan items: language tapes and books. 
AUM defines this category as an IS-A/generalization-specialization relationship, where one concept is more general or specialized than another.
