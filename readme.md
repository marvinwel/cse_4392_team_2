## 🎯 Course Overview

This course explores the use of **Generative AI techniques, tools, and frameworks** within software engineering and the Software Development Life Cycle (SDLC).

Major topics include:

- Generative AI and its applications in the SDLC
- Prompt Engineering
- Evolutionary Prompt Optimization
- Agile Unified Methodology (AUM)
- Generative AI tools for software development
- Embeddings and Vector Databases
- Retrieval-Augmented Generation (RAG)
- LangChain
- Automated Code Refactoring
- AI Agents
- LangGraph
- Prompt Templates and Optimization
- Generative AI Security and Ethics
- AI-Powered Application Development

## 🌿 Git Workflow

Team members should create a separate branch when working on significant changes.

### Create a Branch

```bash
git checkout -b feature/feature-name
```

### Stage Changes

```bash
git add .
```

### Commit Changes

```bash
git commit -m "Describe your changes"
```

### Push Changes

```bash
git push origin feature/feature-name
```

A Pull Request can then be created for the team to review before merging changes into the `main` branch.
